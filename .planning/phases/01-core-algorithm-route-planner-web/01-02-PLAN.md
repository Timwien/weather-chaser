  <behavior>
    scoreLocation(hourlyData, arrivalDate, nightsStay, weights) → WeatherScore

    Temporal slicing:
    - arrivalDate = 2024-07-10, nightsStay = 2 → use hours for July 10 and July 11 only (48 hours)
    - arrivalDate = 2024-07-10, nightsStay = 1 → use hours for July 10 only (24 hours)
    - Hours outside the stay window are excluded from all averages/sums

    Normalization (all outputs 0–100 before weighting):
    - sunshine: normalize(avgSunshineSecondsPerHour, min=0, max=3600) * 100 — higher = better
    - precipitation: (1 - normalize(totalPrecipMm, min=0, max=20)) * 100 — lower = better (inverted)
    - temperature: normalize(avgTempC, min=5, max=30) * 100 — warmer = better
    - wind: (1 - normalize(avgWindKmh, min=0, max=50)) * 100 — calmer = better (inverted)
    - normalize(v, min, max): clamp((v - min) / (max - min), 0, 1)

    Composite: sum of (dimensionScore * weight) for all four dimensions

    PRESETS (from RESEARCH.md):
    - beach:       { sunshine: 0.4, precipitation: 0.3, temperature: 0.2, wind: 0.1 }
    - hiking:      { sunshine: 0.3, precipitation: 0.3, temperature: 0.2, wind: 0.2 }
    - sightseeing: { sunshine: 0.3, precipitation: 0.4, temperature: 0.2, wind: 0.1 }

    Test cases:
    - sliceHoursByDays: 72-hour dataset, arrival = day 2, nights = 1 → returns exactly 24 hours (indices 24–47)
    - sliceHoursByDays: 72-hour dataset, arrival = day 1, nights = 2 → returns exactly 48 hours (indices 0–47)
    - scoreLocation with perfect weather (max sunshine, 0 precip, 30°C, 0 wind, equal weights) → composite ≈ 100
    - scoreLocation with bad weather (0 sunshine, 20mm precip, 5°C, 50 km/h wind, equal weights) → composite ≈ 0
    - scoreLocation same data, beach vs sightseeing preset → different composite (sightseeing weights precip more)
    - normalize(0, 0, 100) → 0; normalize(100, 0, 100) → 1; normalize(150, 0, 100) → 1 (clamped); normalize(-10, 0, 100) → 0 (clamped)
