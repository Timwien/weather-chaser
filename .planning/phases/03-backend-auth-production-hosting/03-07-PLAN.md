  <name>Task 2: Deploy to Vercel and smoke-test proxy endpoints</name>
  <files>apps/web/vercel.json</files>
  <action>
Deploy to Vercel using the CLI. First install if needed: `npm install -g vercel`. Then from the repo root:

```bash
cd apps/web && vercel --prod
```

After deployment completes, smoke-test all proxy endpoints using curl or fetch against the production URL. The production URL will be weatherchaser.vercel.app (or the URL shown by the CLI).

Run these smoke tests:

```bash
PROD_URL="https://weatherchaser.vercel.app"

# Weather proxy (6h cache)
curl -I "${PROD_URL}/api/proxy/weather?latitude=48&longitude=11&forecast_days=3"
# Expect: 200 OK, Cache-Control: public, s-maxage=21600

# Nominatim proxy (1h cache)
curl -I "${PROD_URL}/api/proxy/nominatim?q=M%C3%BCnchen&limit=3"
# Expect: 200 OK, Cache-Control: public, s-maxage=3600

# Keepalive
curl "${PROD_URL}/api/keepalive"
# Expect: {"status":"ok"} or similar 200

# Delete endpoint (no token — should 401)
curl -X DELETE "${PROD_URL}/api/user/delete"
# Expect: 401 Unauthorized

# SPA routing — non-API path should return index.html (not 404)
curl -s "${PROD_URL}/trip/abc123" | grep -c "<title>"
# Expect: 1 (title tag found = SPA rewrite working)
```

If any smoke test fails:
- 404 on /api/* → check vercel.json rewrites pattern
- 500 on /api/keepalive → check SUPABASE_URL and SUPABASE_ANON_KEY env vars in Vercel
- /trip/abc123 returns 404 → fix the SPA rewrite negative lookahead in vercel.json

After smoke tests pass, confirm the build output: `cat apps/web/dist/index.html | grep -c "VITE_SUPABASE_URL"` should return 0 (env vars inlined by Vite but by reference to VITE_ prefix, not the actual value in the HTML — the actual values ARE in the bundle JS but that's expected for VITE_* public vars).
