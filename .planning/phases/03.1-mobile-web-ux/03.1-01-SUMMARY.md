# Phase 3.1 Plan 01: Mobile Bottom Sheet Foundation Summary

**Dependency-free 3-snap draggable MobileBottomSheet with ref-driven 60fps drag, single-source-of-truth getSheetHeights(), and SSR-safe useIsMobile hook — all token-themed, no new runtime dependencies**

## Accomplishments

- `useIsMobile()` hook using matchMedia at 768px with change listener cleaned up on unmount, SSR-safe (typeof window guard)
- `MobileBottomSheet` controlled component (snapIndex 0|1|2 + onSnapChange): handle-only pointer drag via setPointerCapture, ref-driven CSS transform during drag (no React state), nearest-detent snap on release
- `getSheetHeights()` exported as the SINGLE SOURCE OF TRUTH for peek (84px), half (50dvh), full (100dvh) — sheet derives its own translateY from it; Plan 03 imports this same function for map padding
- Scrim rendered and pointer-interactive only at snapIndex 2 (full); tap on scrim calls onSnapChange(1)
- Tap-to-advance (< 6px movement) cycles peek→half→full on handle click
- CSS: 100dvh + safe-area-inset fallback, design tokens throughout (only scrim rgba excepted), overflow:visible on wrapper so DateRangePicker popover is never clipped
