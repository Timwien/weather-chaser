## Decisions Made

- `criterionIcons.tsx` uses `.tsx` extension (not `.ts`) because the file contains JSX — consistent with all other icon-bearing files in the project
- Collapsed pill label derived purely from store state (searchAreas[0].name, tripConfig dates, tripConfig.criteria[0]) — no new data fetch required
- Date formatting uses `Intl.DateTimeFormat` keyed on `i18n.language` — locale-aware (de-DE / en-GB) without hardcoded locale strings
- Mode toggle derives active segment from store `mode` field: `weather-finder` → finder button active, any other mode → route button active; idle defaults to route (safest default)
- Ownership boundary enforced: MobileSearchBar renders only DateRangePicker + LocationInput + CriteriaSelector inside the expanded form — RouteConfigStep, WeatherFinderStep, and useOptimizer are absent (confirmed by grep in verification)
