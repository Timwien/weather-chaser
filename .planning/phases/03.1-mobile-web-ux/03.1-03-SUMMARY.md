# Phase 03.1 Plan 03: Map-first mobile composition Summary

Composed the final mobile layout in `routes/index.tsx`: full-screen map, floating search pill that expands into the single EntryPanel search surface, and a 3-snap bottom sheet that exists only when results (route or finder) are present. MobileTabBar and the old `data-mobile-view` two-screen mechanism were removed in commits 37e1b99/d15ea59.

## Deviation from plan

The plan placed EntryPanel inside the bottom sheet. Execution (commit d15ea59) moved it into the expanded search pill instead and made the sheet results-only. This removed the duplicate-surface problem and made search launchable from the top. All other must-haves hold: auto-snap to HALF on results, FULL on list-item tap, marker taps decoupled from snap, pill hides at FULL, snap heights from `getSheetHeights()`, localized peek summary.

## Post-checkpoint fixes (this session, commit 98c54b3)

Headless device-emulation verification (puppeteer, 390px) found and fixed:
1. Expanded search surface stayed open over the results sheet → auto-collapse on results.
2. Pill in results mode expanded an empty surface → pill hidden while results show.
3. Map never fit a newly generated route (only on stop selection) → fit on route load + snap changes.
4. Hardcoded German save labels in EN locale → `save.*` keys (EN/DE 188/188 parity).
5. favicon 404 → SVG favicon added.
