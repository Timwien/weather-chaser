# Phase 3.2: Premium UI Overhaul

**Goal**: Elevate the web application's user interface to a premium state-of-the-art design, featuring modern typography, glassmorphism, dynamic micro-animations, and an intelligent Dark Mode. All new UI text will use translation keys to strictly support i18n (English and German).

*Note: All updates will take place inside the `apps/web` React application. The `index.html` and `app.js` in the root folder are legacy prototype files.*

## Tasks

### 1. Structure & i18n Enforcement
- Audit the existing React components inside `apps/web/src/components` and ensure all UI text is passed through the existing `useTranslation()` hook.
- Enforce the new rule: no hard-coded English/German strings anywhere in the JSX.

### 2. Premium Typography & Theme Base
- Replace generic system fonts with a premium Google Font (like 'Inter' or 'Outfit').
- Implement CSS variables (`apps/web/src/styles/`) for a cohesive brand palette: vibrant indigos, clean slates, and neon accents.

### 3. Glassmorphism Aesthetics
- Apply `backdrop-filter: blur(16px)` and highly translucent background colors (`rgba(255, 255, 255, 0.7)`) to major UI elements like the control panels, results cards, and tabs.
- Ensure the background underneath the glass panels has a vibrant, modern gradient.
- Replace harsh single-colored box-shadows with soft, multi-layered shadows to give a 3D elevated feel.

### 4. Auto Dark Mode & State Management
- Create an intelligent Dark Mode that defaults to the user's OS preference (`prefers-color-scheme`).
- Add a user-facing toggle to let them override the OS setting.
- Persist the user's manual choice using `zustand` (and sync it to local storage + database preferences if logged in).
- Recalculate all Glassmorphism variables for dark mode (e.g., swapping to deep charcoal glass with neon borders).

### 5. Micro-animations & Fluid Interactivity
- Add active and hover state micro-animations for all buttons (e.g., `transform: scale(1.02)`).
- Implement smooth transitions for any UI elements entering or leaving the screen context.

## Verification
- Test that flipping between Light/Dark mode transitions smoothly without flashing, and remembers the user's choice upon refresh.
- Run the localized app in both English and German to ensure no un-translated UI text spills through layout bounds.
