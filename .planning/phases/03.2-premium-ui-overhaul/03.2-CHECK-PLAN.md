# Phase 3.2 — Browser Check-Plan (autonomous)

A self-contained, agent-runnable verification plan for **Auto Dark Mode** and **i18n
enforcement**. Designed for a browser-capable Claude (Playwright, Puppeteer/CDP, or a
browser MCP). Each step lists the **action** and the **expected observation** (the
pass condition). Capture a screenshot at every 📸 marker as evidence.

## Preconditions / setup

1. Start the dev server from the repo root:
   ```bash
   pnpm --filter @weatherchaser/web dev      # serves http://localhost:5173
   ```
2. Launch the browser. **Abort all non-`localhost` requests** (map tiles, Google Fonts,
   Overpass/Open-Meteo/OSRM/Nominatim). The DEV build auto-runs a search pipeline + web
   workers + streams map tiles; leaving that network on saturates the page main thread
   and stalls automation. Theme + i18n do not depend on any of it.
   - Playwright: `await page.route('**/*', r => r.request().url().startsWith('http://localhost') ? r.continue() : r.abort())`
3. `BASE = http://localhost:5173/`.

Key handles (from the code):
- Theme state lives on `document.documentElement` as the **`data-theme`** attribute (`"light"` | `"dark"`).
- Theme persistence: `localStorage['wc-theme']` ∈ `{system, light, dark}`. A pre-paint
  `<script>` in `index.html` sets `data-theme` from it before first paint.
- Language persistence: `localStorage['i18nextLng']` ∈ `{en, de}` (i18next-browser-languagedetector).
- Account button: `.entry-panel-account-btn` (opens the account modal).
- Settings tab buttons & theme/lang buttons: `.settings-tab-lang-btn` (theme buttons read
  "System/Light/Dark" or "System/Hell/Dunkel"; lang buttons read "Deutsch"/"English").
- Tagline: `.entry-panel-tagline` (EN "Chase perfect weather" / DE "Jage das perfekte Wetter").

## A. Auto Dark Mode

**A1 — OS default = light.** Emulate `prefers-color-scheme: light`; `localStorage.removeItem('wc-theme')`; reload.
→ **PASS** if `documentElement[data-theme] === "light"`. Record `getComputedStyle(body).backgroundColor`. 📸

**A2 — OS default = dark.** Emulate `prefers-color-scheme: dark`; remove `wc-theme`; reload.
→ **PASS** if `data-theme === "dark"` **and** body background-color differs from A1 (proves the dark token block applies). 📸

**A3 — Stored override beats OS + persists.** OS = light; `localStorage.setItem('wc-theme','dark')`; reload.
→ **PASS** if `data-theme === "dark"` after reload (override persists, beats light OS).

**A3b — No flash (pre-paint).** With `wc-theme='dark'` still set, open a fresh page and read
`data-theme` at `domcontentloaded` (before React mounts).
→ **PASS** if it is already `"dark"` at DCL (the inline script set it pre-paint; no light→dark flash).

**A4 — Light override beats dark OS.** OS = dark; `wc-theme='light'`; reload.
→ **PASS** if `data-theme === "light"`.

**A5 — Settings control is wired.** OS = light; `localStorage.clear()`; reload (expect light).
Click `.entry-panel-account-btn` → click the Settings tab (button whose text matches
`/settings|einstellungen/i`) → click the theme button whose text matches `/^(dark|dunkel)$/i`.
→ **PASS** if `data-theme` flips to `"dark"` **and** `localStorage['wc-theme'] === "dark"`. 📸

**A6 — Live OS sync while System.** Set `wc-theme='system'`; reload; emulate
`prefers-color-scheme: dark` **without reloading**.
→ **PASS** if `data-theme` switches to `"dark"` live (matchMedia listener), then back to
`"light"` when emulating light again.

## B. i18n enforcement

**B1 — German.** `localStorage.setItem('i18nextLng','de')`; reload.
→ **PASS** if `.entry-panel-tagline` ≈ "Jage das perfekte Wetter" and `.entry-panel-account-btn`
`aria-label === "Konto"`. 📸

**B2 — English.** `i18nextLng='en'`; reload.
→ **PASS** if tagline ≈ "Chase perfect weather" and account `aria-label === "Account"`. 📸

**B3 — No German leak in EN.** In EN mode, read `document.body.innerText`.
→ **PASS** if none of `["Reisedaten","Hinzufügen","Einstellungen","Konto","Startort","Löschen"]` appear in the visible entry view.

**B4 — Saved-tab strings (needs login).** Sign in, open account modal → Saved tab, in both
languages. → **PASS** if section titles localize: "Routes/Routen", "Finder searches/Finder-Suchen",
"Favorites/Favoriten", and empty states ("No routes saved yet"/"Noch keine Routen gespeichert").
*(Guest mode shows only the "sign in" notice — log in to reach these.)*

**B5 — aria-labels localize.** Compare `aria-label` of the account button and date-picker nav
buttons (`/Previous month|Vorheriger Monat/`) across languages. → **PASS** if they switch.
